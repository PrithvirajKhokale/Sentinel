# Sentinel — Demo Flow

## 1. Open Dashboard

Show the Sentinel project portfolio dashboard.

## 2. Portfolio Overview

Display:
- Total projects
- Projects by risk category
- Risk distribution
- Relevant trends

## 3. Filter Projects

Filter the portfolio based on:
- Ministry
- Sector
- Risk level
- Other available project attributes

## 4. Select a Project

Open an individual project's intelligence page.

## 5. Project Intelligence

Display:

- Project information
- Progress
- Schedule information
- Cost information
- Predicted time-overrun probability
- Expected delay
- Cost-overrun probability
- Overall risk score
- Risk category

## 6. Explainability

Show the major factors contributing to the prediction using SHAP.

## 7. Alerts / Prioritization

Demonstrate how high-risk projects can be identified and prioritized.

## 8. Trends and Analytics

Demonstrate relevant project trends and benchmarking.

## 9. Final Message

Demonstrate that Sentinel is intended to move project monitoring from purely status reporting toward predictive risk identification and decision support.
