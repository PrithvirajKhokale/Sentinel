# Sentinel API documentation

The local backend implements project list/detail, monthly history and portfolio summary, plus validated transactional import and database migrations. History and portfolio use the validated PostgreSQL snapshots and adjacent comparisons. See [local backend setup](backend-local.md). The proposed FastAPI/Pydantic monitoring endpoints, envelopes, filters, pagination, errors and validation rules are defined in [API contract v1](api_contract.md). Representative responses from validated April-August records are in [contract examples](examples/project-data-contract.json).

The initial demo is local on loopback only, with React + Vite and the retained FastAPI/Pydantic backend and PostgreSQL/SQLAlchemy storage. Authentication and authorization are required before any shared deployment; their implementation/provider are deferred. Dataset revisions are identified by canonical manifest SHA-256, not the history CSV hash alone. No prediction endpoint or completion-status claim is part of this proposal. See [architecture](architecture.md) for boundaries and stack decisions.
